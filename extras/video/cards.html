Architecture
The LLM never touches money.
It returns one label from a closed enum of 17 root causes, with a confidence score. A deterministic policy table turns that label into a proposed action. A deterministic guardrail engine decides whether it may fire.

The model
A label. Nothing else.
1 of 17 causes + confidence. Forced tool use, schema-validated. It may write message text — never the action, amount, timing or recipient.
→
Policy table
Data, not code
cause → action, channel, schedule. Stamps a policy_ref on every decision so it traces back.
→
Guardrail engine
14 rules, fail closed
Consent · DND · quiet hours · frequency cap · value ceiling · confidence floor · idempotency · promise window …
So a hallucination is harmless by construction.  The worst a wrong label can do is cause a badly-timed retry — never a wrong charge.
